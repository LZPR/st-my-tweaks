# 姿态发送档位的成本与准确率

在「可视化输入 → 设置」中选择默认档位，或在姿态编辑器里为本条消息临时改选。五档共用同一组编辑点位，含图的三档共用同一张 800 × 880 PNG。混合档通过改变随图文本的内容来调节预算。文字始终在图片前面，输入框中的问题和手写注释均保留。仅图档有手写注释时会额外附上注释原文。[设置截图](screenshots/pose-settings.png)

## 对照设计

2026-11-25，通过 SillyTavern 自定义连接调用 deepseek-flash。复用先前的 12 个合成姿态，每档各测思考、非思考两种模式，共 120 个有响应的请求。每次只有一条用户消息，手写注释留空，温度为 0，输出上限为 2048 token，图片 detail 为 auto。发送档位只改变附件，用户在 ST 选择的模型和思考设置照常生效。[样例坐标及前四题标准答案](pose-deepseek.md)

每例一次回答六题。前四题判断双腕高低、哪些腕高于同侧肩、哪些腕越过颈部中线、哪侧膝内角更小。后两题判断颈部在画面中心左侧、右侧或线上，以及哪侧踝到同侧膝的水平距离绝对值更大（允许相等）。新增两题用于检验摘要以外的细节；仅摘要无法唯一决定答案。各题独立计分，缺答、弃答均不得分，有解释的回答按最终六项结论计分。每种组合只测一遍。

## 成本口径

用每个成功返回请求的 usage 汇总缓存命中、未命中的输入 token 和全部输出 token（含推理），折算成同样请求重复 100 次的价格。上表按 DeepSeek Flash 官方人民币空闲时段单价估算，每百万 token 分别为 0.02、1、4 元。同一用量按高峰价计算为表中金额的两倍。网络失败后补齐的请求以有 usage 的响应计入；结果为估算，未核销账单。真实聊天的历史长度、缓存命中、输出长度及供应商计费都会改变成本。[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

本批样本适合比较精确的二维几何问答。完整坐标能推导后两题，摘要里的腕部和膝角也直接有助于前四题。结果不能用于估计开放式动作描写、多人遮挡或其他模型的正确率。
